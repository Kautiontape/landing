MCP Servers

Model Context Protocol servers hosted at mcp.kautiontape.com. Connect them to Claude Desktop or any MCP-compatible client to get Magic: The Gathering data at your fingertips.

🃏 Scryfall
Search Magic: The Gathering cards, look up pricing, find cards by name, and get random cards. Powered by the Scryfall API.
Available tools
scryfall_search scryfall_named scryfall_price scryfall_price_list scryfall_random
SSE Endpoint
https://mcp.kautiontape.com/scryfall/sse
⚔️ EDHRec
Commander deck recommendations, top cards by theme or color, combo lookups, average decklists, and community salt scores.
Available tools
edhrec_commander edhrec_recommendations edhrec_top_cards edhrec_combos edhrec_average_deck edhrec_salt
SSE Endpoint
https://mcp.kautiontape.com/edhrec/sse

Quick Setup

Add these to your Claude Desktop config (claude_desktop_config.json) under mcpServers: 

{
  "mcpServers": {
    "scryfall": {
      "url": "https://mcp.kautiontape.com/scryfall/sse"
    },
    "edhrec": {
      "url": "https://mcp.kautiontape.com/edhrec/sse"
    }
  }
}

No authentication required. These are public, read-only servers.
